# 电机板电气监督首次标定与测试

> 当前固件保持 `limits_approved=0`。本流程第一阶段只采数据，不能启动车轮；
> 不得把 `NOT_APPROVED` 手工改成通过来跳过测量。

## 1. 准备

- 小车架空，左右轮无接触，周围无人；
- 准备独立断电手段、万用表和115200波特率UART记录；
- 确认烧录BIN的SHA256与交付报告一致；
- 电机板母线、电机和编码器接线保持正式整车状态。

## 2. 静止采集

上电后记录至少10秒的：

```text
POWER,valid=1,raw=bus,left,right,bus_mv=...,current_ma=left,right,zero=left,right,samples=...,fault=0x..,ready=..
```

通过条件：

- 约1.28秒后`samples=64`；
- 只使用`valid=1`记录；`valid=0`表示本周期ADC样本不可用于拟合；
- 左右零点均不超过19 ADC码，静止后`current_ma`接近0；
- 万用表母线电压与`bus_mv`方向一致，记录两者用于拟合增益/偏置；
- `fault=0x02`且`ready=0`是当前预期，表示阈值尚未批准；
- 不得出现ADC、欠压、过压或峰值电流故障位。

若零点窗口无法完成、原始值抖动明显或母线换算错误，停止后续测试，先查模拟地、
分流器、INA180、VDDA和分压网络。

## 3. 批准输入

提交以下原始证据后才能生成运动测试配置：

- 10秒完整POWER日志；
- 同时刻万用表母线电压；
- 电机型号、额定/启动/堵转电流或独立台架测量；
- 允许的持续时间、线束/连接器和驱动器热条件。

由这些独立量计算电流增益、母线增益/偏置、UV/OV迟滞和峰值持续时间。批准配置
必须重新构建并记录Hash；不能直接沿用临时3A/33V硬件上限作为电机保护结论。

## 4. 批准后的架空顺序

1. STOP、ESTOP、租约到期和旧Reference屏障；
2. 左右轮正向、反向及编码器符号；
3. 最高速度制动后，连续3个原始零速样本前不得反向；
4. 单轴反馈断开/反向时，两轴同周期停车；
5. 单轮轻载受阻、电流故障和显式两阶段CLEAR；
6. 最后才允许低速落地与随机磁道测试。

每一门失败都回到STOP并保留日志，不继续下一门。
