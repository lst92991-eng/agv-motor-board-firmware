# 电机板电气监督首次标定与测试

> 当前生产Target按用户要求启用开发动态验收配置：6串母线18.0V跳闸/19.2V恢复、
> 25.2V恢复/25.8V跳闸，单电机0.8A持续100ms跳闸。它允许受监控的动态开发验收，
> 但不替代最终产品的电流、电压和热证据。

## 1. 准备

- 小车架空，左右轮无接触，周围无人；
- 准备独立断电手段、万用表和SWD调试器；
- 确认烧录BIN的SHA256与交付报告一致；
- 电机板母线、电机和编码器接线保持正式整车状态。

## 2. 静止采集

当前精简固件不保留调试UART和独立电气诊断PDO。连接生产AXF对应的SWD调试会话，
周期读取并导出至少10秒的：

```text
adc_raw[0..2] = bus,left,right
power_data = bus_mv,left_current_ma,right_current_ma,left_zero_raw,right_zero_raw,zero_samples,fault_mask,ready
```

`adc_raw[0]`对应PA3母线，`adc_raw[1]`对应PA4左电流，`adc_raw[2]`对应PA5右电流。
若当前SWD工具不能导出连续记录，动态开发仍可依靠现有本地保护继续，但不得把本轮
结果表述为最终电气标定完成。

通过条件：

- 约1.28秒后`samples=64`；
- 只使用连续更新且没有`POWER_FAULT_ADC`的记录；ADC超时周期不可用于拟合；
- 左右零点均不超过19 ADC码，静止后`current_ma`接近0；
- 万用表母线电压与`bus_mv`方向一致，记录两者用于拟合增益/偏置；
- 静止零点完成后`fault_mask=0`且`ready=1`；CAN `0x481`的`warning_mask`应为0；
- 不得出现ADC、欠压、过压或峰值电流故障位。

若零点窗口无法完成、原始值抖动明显或母线换算错误，停止后续测试，先查模拟地、
分流器、INA180、VDDA和分压网络。

## 3. 批准输入

提交以下原始证据后才能生成运动测试配置：

- 10秒完整POWER日志；
- 同时刻万用表母线电压；
- 电机型号、额定/启动/堵转电流或独立台架测量；
- 允许的持续时间、线束/连接器和驱动器热条件。

由这些独立量计算电流增益、母线增益/偏置、UV/OV迟滞和峰值持续时间。批准配置
必须重新构建并记录Hash；不能直接沿用临时3A/33V硬件上限作为电机保护结论。

## 4. 批准后的架空顺序

1. STOP、ESTOP、租约到期和旧Reference屏障；
2. 左右轮正向、反向及编码器符号；
3. 最高速度制动后，连续3个原始零速样本前不得反向；
4. 单轴反馈断开/反向时，两轴同周期停车；
5. 单轮轻载受阻、电流故障和显式两阶段CLEAR；
6. 最后才允许低速落地与随机磁道测试。

每一门失败都回到STOP并保留日志，不继续下一门。
